# Skill : Add New Page (Création d'une nouvelle page)

## Quand utiliser ce skill
- Pour ajouter une page dédiée (ex: une page dédiée à la filière Textile).
- Pour créer une page d'atterrissage (landing page) ou une nouvelle rubrique.

## Procédure séquentielle
1. **Cadrage** : Définir l'objectif de la page et valider avec le client.
2. **Rédaction** : Le Copywriter rédige le texte via `write-page-content`.
3. **SEO** : Le SEO Specialist enrichit titres et meta-tags via `seo-optimize-content`.
4. **Code HTML/CSS** : Le Web Developer intègre la page avec `create-html-structure`, le header et le footer.
5. **Navigation** : Ajouter le lien dans le menu et le footer si nécessaire.
6. **Sitemap** : Déclarer la nouvelle URL dans `sitemap.xml`.
7. **Contrôle Qualité** : Le QA audite l'accessibilité et la conformité au cadrage.

## Sorties attendues
- Nouvelle page HTML créée.
- Sitemap et navigation actualisés.
