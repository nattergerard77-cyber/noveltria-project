## Règles d'utilisation de la mémoire

1. **Lire avant d'agir** : Chaque agent lit MEMORY.md + le fichier pertinent avant toute tâche.
2. **Mettre à jour après validation** : Toute décision validée par le client est ajoutée à decisions.md.
3. **Ne jamais supposer** : Si une information manque en mémoire, demander au client.
4. **Ne jamais modifier** une décision validée sans signal explicite du client.
5. **Dater les entrées** : Chaque modification est datée (format AAAA-MM-JJ).
