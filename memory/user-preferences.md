# user-preferences.md — Préférences de Laurent Huiskens

> Ce fichier documente les préférences, habitudes et attentes du porteur de projet.
> À enrichir au fil des sessions de travail.

---

## Préférences de méthode de travail

| Préférence | Détail |
|------------|--------|
| Validation étape par étape | Chaque étape doit être validée avant de passer à la suivante |
| Plan strict | Suivre le plan à la lettre sans se mélanger |
| Clarté avant tout | Expliquer les concepts simples avant d'agir |
| Collaboration active | Travailler ensemble, pas en autonomie totale |
| Pas de suppositions | Si une info manque, demander plutôt que supposer |

## Préférences de communication

| Préférence | Détail |
|------------|--------|
| Style de réponse | Clair, structuré, sans jargon inutile |
| Questions | Poser des questions ciblées avant d'agir |
| Explications | Expliquer le "pourquoi" avant le "comment" |
| Format des livrables | Fichiers lisibles (.md, .html) avec liens directs |

## Points à clarifier avec le client

- Direction visuelle souhaitée (couleurs, ambiance, références visuelles)
- Marchés géographiques prioritaires
- Secteurs conditionnels à confirmer
- Nom de domaine envisagé
- Hébergement web préféré
- Adresse email de contact pour le formulaire
- Numéro de téléphone de contact (si souhaité)
